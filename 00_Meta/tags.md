# 태그 체계

태그는 보조 수단. 1차 분류는 프론트매터 필드 사용.

## 수준
- `#level/intro` 입문
- `#level/mid` 중급
- `#level/adv` 고급

## 주제 (Topic)
- `#topic/llm` LLM 기초
- `#topic/rag` RAG
- `#topic/agent` Agent / Tool Use
- `#topic/finetune` Fine-tuning
- `#topic/eval` 평가/벤치마크
- `#topic/infra` 인프라/배포
- `#topic/prompt` 프롬프트 엔지니어링

## 목표 (Goal)
- `#goal/career` 취업/이직
- `#goal/side` 사이드 프로젝트
- `#goal/research` 연구
- `#goal/biz` 비즈니스 적용

## 상태
- `#status/active`
- `#status/inactive`
- `#status/dropped`

## 운영
- `#ops/decision`
- `#ops/todo`
- `#ops/blocker`

## 추가 규칙
- 태그 신설 시 이 문서에 먼저 등록
- `Tag Wrangler` 플러그인으로 일괄 관리
