# P001_example 개인 공간

이 폴더는 P001_example의 개인 학습 공간입니다.
다른 참가자도 읽을 수 있지만, **이 폴더에 쓸 수 있는 사람은 P001_example뿐**입니다.

## 구조

```
personal/P001_example/
├── hot.md          내 최근 학습 컨텍스트 (vault-sync가 갱신)
├── log.md          내 학습 활동 로그
├── inbox/          내 읽기 대기열
└── notes/
    ├── sources/    내가 처리한 소스 요약 (personal-ingest 결과)
    ├── concepts/   개념 초안 (공유하기 전 작업 공간)
    └── questions/  내 Q&A 기록
```

## 스킬 사용

```
/vault-sync         공유 위키 최신 내용 → 내 hot.md 갱신
/personal-ingest    소스 → 이 폴더의 notes/에 정리
/wiki-query         공유 + 내 지식 통합 검색
/contribute         notes/ → 공유 wiki PR 생성
```
