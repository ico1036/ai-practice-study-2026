# inbox

**기여 드롭존** — 형식 몰라도 됩니다. 뭐든 여기 넣으세요.

## 사용 방법

1. 공유하고 싶은 자료나 노트를 이 폴더에 파일로 저장
2. 그게 전부입니다

주간 트리아지에서 Vault Keeper가 정리합니다:
- 논문/아티클 → `.raw/` 이동 후 `wiki-ingest` 처리
- 개념 노트 → `wiki/concepts/` 또는 `wiki/techniques/` 배치
- 링크/URL → 처리 후 `wiki/sources/` 추가
- 세션 관련 내용 → `ops/sessions/` 반영

## 또는 직접 기여하려면

형식을 갖춘 노트는 `/contribute` 스킬로 직접 PR을 만들 수 있습니다.

```
/contribute _personal/notes/concepts/내노트.md
```
