# 니즈 클러스터링

참가자 니즈를 의미적 그룹으로 묶은 결과. 정기 업데이트.

## 최신 분석
- 분석일:
- 참가자 수: 0
- 클러스터 수: 0

## 클러스터 (예시 템플릿)

### Cluster A: (이름)
- 핵심 키워드:
- 대표 참가자: [[P001_*]], [[P005_*]]
- 추천 트랙:

### Cluster B: ...

## 분석 방법
1. 모든 참가자 `interests + needs_priority` 추출
2. 의미 임베딩 후 클러스터링 (k=5~8)
3. 운영진 검토 후 트랙 매핑

## 변경 이력
- YYYY-MM-DD 초안
